# 実装言語の選定

## 要件

Go、TypeScript、Swift などの利用先に対して、同じ CLI で設定を適用する。
macOS、Linux、Windows に配布し、利用先で CLI 自体のビルドを必須にしない。
ロック、変更計画、衝突、失敗時の復元を型とテストで扱う。

## 候補

Go は単体バイナリの配布と OS 間の移植性に利点がある。
TypeScript は設定編集の周辺ライブラリ、Python は試作の容易さに利点がある。

## 選定理由

Go を採用する。CLI の実行に追加の言語ランタイムを要求せず、
標準ライブラリでファイル処理、Git の呼び出し、整形の確認を実装できる。
YAML、JSON Schema、TOML の解析には版を固定した依存を使う。
利用先は Go module が１つある構成に加え、`python-uv` プロファイルで
ルートまたは指定ディレクトリの単一 Python パッケージを扱う。CLI 本体は Go を継続する。
